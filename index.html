    🗺️ 主线与章节

    主线按章节往下走：通过一关（至少 1 星）才解锁下一关，没解锁的关卡在关卡记录里点不开。

    「🗺️ 章节地图」只显示你走到的那一章，打完才出现下一章；每章第一关会播一小段剧情，可跳过，看过就不再播。

    ♾️ 更多玩法

    主页「🎮 更多玩法」里有三个独立挑战，成绩单独记录、不影响主线：

    · 无尽模式：40 步自由发挥，连击越猛分越高
    · 60 秒冲刺：60 秒内能刷多少分
    · 节奏关卡：90 秒，下方节拍条走到最右端并「滴答」一声就是节拍点，前后约 0.17 秒内消除得分 ×1.5

    三个模式各自保存最高分，不提供续命，步数 / 时间用完就结算。

    🪙 金币、道具与背包

    通关、每日任务、签到都给金币，可在商店买道具：+3 步（限时关改成 +10 秒）、洗牌、撤回、开局炸弹、彩虹。

    买到后进背包（主页音乐键下方 / 游戏界面 🎒）点「使用」才生效。商店会先弹确认框再扣金币，防手滑。

    洗牌和撤回每局各送 3 次，用完不自动补；还想用就在背包里用道具加次数。

    📅 每日挑战与任务

    每日挑战：每天固定牌面（所有人同一局），步数固定，目标分随日期递增，通关给金币；拿到 3 星当天封盘，再进去显示「已完成今日挑战」和当日战绩。

    每日任务：每天 3 个，完成回任务面板领金币。

    🎁 福利中心

    签到：每天 1 次，7 天一轮，金币 50 → 80 → 120 → 180 → 250 → 350 → 500，第 7 天额外送 1 个彩虹；断签从第 1 天重算，漏签可花 300 金币补（只补连续天数，不发当日奖励）。

    每日转盘：每天免费 1 次，奖 50～300 金币或「洗牌 +1」「撤回 +1」。

    📮 邮箱

    左上角 🏠 下面的 📮 收系统公告和奖励，有新邮件时亮红色角标（数字 = 未读数）。

    邮件左滑出「删除」，没领奖励的删不了；「返回」上面有「✅ 一键已读」「🗑️ 一键删除」，删除需二次确认。

    点开看正文，带奖励的邮件底部点「领取」金币进钱包，每封只能领一次；已读和领取记录跟着账号走。

    🏅 成就与配色

    成就：共 19 枚，每枚 5 阶（灰 → 铜 → 银 → 金 → 彩），进度越高颜色越高阶；面板里能看到还差多少、下一阶是什么颜色。

    棋盘配色：8 款按累计星星解锁（黄默认、红 10、橙 20、绿 35、青 55、蓝 80、紫 110、黑 150）。只改棋盘外圈光晕和目标栏底色，不影响分数、步数和难度。

    📊 排行榜与奖牌

    进去先选榜：总榜 → 省榜 → 局榜。总榜按总分（每关最高分之和），省榜先选省再列该省玩家，局榜先选某一关只比这局最高分。列表页只有标题、选择器和名次，想看别的榜返回上一层重选。

    打完分直接上共享榜，别人更新时你开着榜单会立刻刷新，最多显示 20 名；0 分不上榜，显示「未上榜」。

    奖牌：前三名挂 🥇 🥈 🥉，榜上只有自己也算名次。主页贴在「本关最高分」的分数左边，关卡记录里在星星左边。

    🎵 音乐与音量

    设置 → 🎵 音乐设置 → 音乐库：除内置歌曲，还能粘贴 MP3 / M4A 直链或 QQ音乐 / 网易云分享链接自动入库，入库后可长按或左滑重命名。

    可把歌加进播放列表，支持顺序 / 随机 / 循环、无缝切歌。

    排序：长按某首歌让它浮起，拖到位置松手；长按只负责排序，重命名 / 删除只能左滑一首一首来（手机上同样支持，按住时列表不会跟着滚）。

    音量：所有歌响度自动对齐不会忽大忽小，拖动滑块实时试听，音量会记住。游戏里 🎵 键只关背景音乐，音效照常，旁边是 🎒 背包、📖 规则、⚙️ 设置。

    👤 账号与昵称

    第一次进来先选登录或注册：注册只需名字 + 密码（4~24 位，不含空格）就是一个新空号；登录要两项都正确，输错提示「名字或密码不正确，请确认后再次输入」。

    昵称：最多 8 字，特殊符号只能用 - . _，名字具有唯一性。改名点左上角 🏠 主页键（📖 规则键在它右边）里的「✏️ 改名」，账号名一起更新。

    切换账号 / 修改密码：设置 → 🔐 账号安全，本机账号都列出来，点一下即切换，金币、星星、进度各自独立。

    注销账号：设置 → 🔐 账号安全 → 🔒 注销账号（切换账号下面）。两步确认后彻底删除进度、星星、金币、背包、成就、邮箱、榜单成绩，无法恢复；只是换号玩请用「切换账号」。

    🎮 玩法规则

    🎮 基本玩法

    交换相邻两块，让 3 个及以上相同图案连成横线或竖线即可消除；左右滑动、点选两格都行，长按可多选。

    每步消耗 1 步数（限时关消耗时间），用完本局结束；剩 5 步（限时关 10 秒）时顶部数字变红提醒。

    退出页面 / 切后台 / 锁屏会自动暂停，回来接着玩，不会白掉步数。找不到步就点 💡 提示（每局 3 次）。

    ✨ 特殊块怎么来

    线消：4 个同图案连成直线 → 横着连的清整行、竖着连的清整列。

    炸弹 💣：L 型 / T 型消除 → 生成炸弹，炸掉周围 3×3；背包的「开局炸弹」也能直接放一颗。

    彩虹 🌈：5 个连成一线 → 生成彩虹。彩虹自己被消掉时触发：清掉全盘同图案方块，彩虹自身也消失。和普通块交换但彩虹没被消时，只按普通三连算。

    结算引爆：步数 / 时间用完时，场上剩余的特殊块会按生成顺序自动引爆，炸得好可能直接反败为胜。

    💥 组合技

    两个特殊块交换触发组合技：

    · 线消 + 线消 → 同向三行 / 三列，垂直交叉则十字爆破
    · 线消 + 炸弹 → 十字炸弹（整行整列 + 周围一圈）
    · 炸弹 + 炸弹 → 5×5 爆炸
    · 彩虹 + 线消 → 全盘同图案变线消
    · 彩虹 + 炸弹 → 全盘同图案变炸弹并引爆
    · 彩虹 + 彩虹 → 全屏清场

    放错了也没关系，还有撤回次数就能退回这一步之前。

    🔥 连击与倍率

    连续消除不断链（间隔 2.5 秒内）累积连击：2 连 ×1.5、3 连 ×2、4 连及以上 ×3，倍率显示在棋盘中央。

    打到 4 连击触发 狂热 6 秒：期间分数再翻一倍，棋盘边缘亮红光，趁这时多消。

    🎯 关卡目标（8 种）

    普通得分：步数内达到目标分。
    收集方块：集齐指定数量与图案的方块（每次开局随机挑两种）。
    清除果冻：清掉棋盘上全部果冻格。
    限时得分：限定时间内达到目标分。
    极限步数：用很少的步数达到目标分。
    敲碎冰块：砸掉指定层数的冰。
    运送钥匙：把钥匙送到最底行。
    护送奶龙：把奶龙送到最底行。

    🧊 障碍与货物

    冰块：冻住的方块不能交换、不参与连消，只能靠旁边消除或特殊块砸开；厚冰多层，越砸越透。

    锁链：锁住的方块第一次被消只解链、方块留下，之后才能正常交换。

    货物（钥匙 / 奶龙）：贴在方块上、发着呼吸光，目标是送到最底行。消掉它下面的方块就往下掉一格，掉到最后一排算送达。

    · 被冰或锁链挡住时先清障碍，否则掉不下去
    · 货物所在方块被消掉时，它会落到被消掉那一格的下面一格，不会消失也不会从顶端重来
    · 目标数量就是场上货物总数，全部送到底即过关

    ⭐ 星级评价怎么算

    每关有两道分数线（2 星线、3 星线），开局前固定写在关卡里，比如第 1 关是 1000 / 1500 / 2000（过关线 / 2 星 / 3 星）。

    · 1 星：完成关卡目标就保底 1 星
    · 2 星：得分到 2 星线，或过关时剩 30% 以上步数
    · 3 星：得分到 3 星线，或过关时剩 60% 以上步数

    也就是分数够了给星，步数省得多也给星，满足一条即可。例：第 1 关 28 步，用 11 步打完（剩 61%）直接 3 星；分数只有 1100，步数剩够 60% 同样 3 星。限时关按剩余时间比例算。

    星星只记历史最好成绩，重打不会掉星。

    📈 分数与纪录

    每关记录最高分和最好星级；没通关只要分数超过历史最高也会记进纪录。

    · 新纪录：结算刷新纪录（含第一次玩）会亮「新纪录」徽章
    · 红色分数：主页和关卡记录里显示红色表示这关还没通关过，通关后变回绿色

    💡 提示与续命

    提示：每局免费 3 次，点 💡 高亮一组可走的交换，用完不补。

    续命：主线关卡步数 / 时间用完时，可花 200 金币再来一次——限步关 +3 步，限时关 +15 秒。每局 1 次，金币不够会提示还差多少；每日挑战和更多玩法没有续命。

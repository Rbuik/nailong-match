    玩法规则

    🎮 基本玩法

    交换相邻的两个方块，让 3 个及以上相同图案连成横线或竖线即可消除。左右滑动、点选两格都能交换，长按可以多选。

    每走一步消耗 1 步数（限时关消耗时间），步数或时间用完即结束本局。步数只剩 5 步（限时关剩 10 秒）时顶部数字变红提醒。

    游戏中退出页面 / 切后台 / 锁屏都会自动暂停，回来时停在暂停面板，不会白掉步数。

    ✨ 特殊块怎么来

    十字线消：4 个同图案连成一条线 → 生成白色十字架块，消除时整行 + 整列一起清（横竖都清）。

    彩虹 🌈：5 个同图案连成一条线 → 生成彩虹块，和任意方块交换，会消掉全盘同图案的方块。

    炸弹 💣：清除果冻关里有概率生成，或从背包使用「开局炸弹」道具放置。爆炸清除周围 3×3 范围。

    结算引爆：步数用完 / 时间到时，棋盘上剩下的特殊块会按生成的先后顺序依次自动引爆——炸得好可能直接反败为胜过关！

    💥 组合技

    两个特殊块交换会触发组合技，威力更强：

    · 线消 + 线消 → 同向三行 / 三列横扫，垂直交叉则十字爆破
    · 线消 + 炸弹 → 十字炸弹（整行整列 + 周围一圈）
    · 炸弹 + 炸弹 → 5×5 大范围爆炸
    · 彩虹 + 线消 → 全盘同图案变线消
    · 彩虹 + 炸弹 → 全盘同图案变炸弹并引爆
    · 彩虹 + 彩虹 → 全屏清场

    组合技放错了也不用怕——只要还有撤回次数，一样能退回这一步走之前的样子。

    🔥 连击与倍率

    连续消除不断链（间隔 2.5 秒内）会累积连击，倍率在棋盘中央显示：

    · 2 连击 → ×1.5 倍
    · 3 连击 → ×2 倍
    · 4 连击及以上 → ×3 倍

    🎯 关卡目标（5 种模式）

    普通得分：在步数内达到目标分数。
    收集方块：集齐指定数量与图案的方块（目标栏会显示该方块的图案）。
    清除果冻：清掉棋盘上全部果冻格。
    限时得分：在限定时间内达到目标分数。
    极限步数：用很少的步数达到目标分数。

    ⭐ 星级评价怎么算

    先说「阈值」：就是每关事先定好的两条分数线——「2 星线」和「3 星线」，跟考试里的「80 分线 / 95 分线」是一个意思。达到线就多一颗星。

    每关开始前，这两条线是固定的，写在关卡里（比如第 1 关是 1000 / 1500 / 2000，第一个数就是过关线，后两个是 2 星线、3 星线）。

    · 1 星：完成关卡目标就保底 1 星
    · 2 星：得分达到 2 星线，或者过关时还剩 30% 以上步数
    · 3 星：得分达到 3 星线，或者过关时还剩 60% 以上步数

    换句话说：分数够了给星，步数省得多也给星，哪边更划算算哪边——两条路任意满足一条就行。

    举例：第 1 关 28 步、星线 1000 / 1500 / 2000。
    · 用 15 步打完（剩 13 步 = 46%）→ 够 2 星的 30%，拿 2 星
    · 用 11 步打完（剩 17 步 = 61%）→ 够 3 星的 60%，直接 3 星
    · 就算分数只有 1100，只要步数剩够 60%，也是 3 星

    限时关按剩余时间比例算。星星只记录历史最好成绩，重打不会掉星。

    🔓 解锁规则

    主线共 20 关。通过某一关（至少 1 星）才会解锁下一关；未解锁的关卡在关卡记录里点不开。

    🏆 分数与纪录

    每一关都会记下本关最高分和历史最好星级：就算没通关，只要分数超过历史最高，也会记进纪录。

    · 新纪录：结算时刷新了纪录（包括第一次玩这一关）就会亮出「新纪录」徽章
    · 红色分数：主页「本关最高纪录」和关卡记录里显示红色，表示这关还没通关过，通关后自动变回绿色

    🎵 音乐与音量

    设置里可以打开音乐库：除了内置的两首歌，还支持粘贴 MP3/M4A 直链或 QQ音乐/网易云音乐的歌曲链接（分享出来的整段文本带《歌名》也行），自动解析成 MP3 入库；入库后可长按/左滑重命名。

    可以把多首歌加进播放列表，支持顺序 / 随机 / 循环，切歌无缝衔接。

    音量：所有歌（包括默认背景音乐）的响度自动对齐，不会忽大忽小；「调节音量」里拖动滑块会实时试听当前正在播放的音乐；音量会记住，下次打开和上次退出时一致。

    音乐键（🔊）只控制背景音乐，关掉后游戏音效照常播放，互不影响。

    🪙 金币、道具与背包

    通关、每日任务、签到都会给金币。金币可在购物商店购买道具：

    · +3 步：本局步数 +3（限时关改为时间 +10 秒）
    · 洗牌：重排棋盘一次
    · 撤回：回到上一步走之前的棋盘（这一步消掉的连锁、目标栏进度一起退回）
    · 开局炸弹：随机位置放一颗炸弹
    · 彩虹：随机把一块变成彩虹

    道具买完进背包（主页音乐键下方 / 游戏界面音乐键左边的 🎒）。局内点「使用」才会生效，全部由你自己决定用不用。

    商店买道具会先弹确认框，确认了才扣金币，防止手滑误买。

    洗牌和撤回每局各送 3 次，但用完后不会自动补——想继续用，得自己在背包里点「洗牌 / 撤回」道具的「使用」按钮把次数加进本局。

    📅 每日挑战与任务

    每日挑战：每天固定牌面（所有人同一局），步数固定，目标分数随日期递增，通关给金币。拿到 3 星后当天封盘，再点进去就是「已完成今日挑战」+ 当日战绩（星星、得分）。

    每日任务：每天 3 个任务，完成后回任务面板领金币；连续签到 7 天奖励递增，第 7 天额外送彩虹道具。

    🗑 注销

    注销会清空全部进度、星星、金币、背包和音乐列表，且不可恢复，需要连续确认两次。

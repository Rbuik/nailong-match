玩法规则

🎈 只记三句：三连就消 · 照目标栏打 · 打不过就买「+3 步」

🎮 怎么玩

交换相邻的两个方块，让 3 个以上同图案连成横线或竖线就能消除（左右滑动、点选两格、长按多选都行）。

每走一步扣 1 步数（限时关扣时间），扣完本局结束。

✨ 特殊块

· 十字架：4 连生成，消除时整行 + 整列一起清
· 彩虹 🌈：5 连生成，和任意方块交换 → 清掉全盘同图案
· 炸弹 💣：清周围 3×3，清果冻关有概率掉，也能从背包放

两个特殊块交换会放组合技，范围更大：线 + 线 十字爆破、炸弹 + 炸弹 5×5、彩虹 + 特殊块 全盘同色变特殊。

🎯 过关目标

得分 / 收集指定方块 / 清光果冻 / 限时得分 / 极限步数。

本关是哪一种、还差多少，看棋盘上方的目标栏就行，不用背。

⭐ 星星怎么来

过关保底 1 星，想多拿星有两条路，满足任意一条即可：

· 得分达到这关的 2 星线 / 3 星线（就是事先定好的两条分数线，跟考试的 80 分线、95 分线一个意思）
· 或者过关时还剩 30% / 60% 以上的步数（限时关按剩余时间算）

两条路取更划算的那条：分数一般但步数省得多，照样能拿 3 星。星星只记最好成绩，重打不掉星。

🪙 金币 · 道具 · 背包

通关、每日任务、签到都给金币，金币去商店买道具：+3 步（限时关 +10 秒）、洗牌、撤回、开局炸弹、彩虹。

道具买完进背包（主页音乐键下方 / 局内音乐键左边的 🎒）。局内点「使用」才生效，用不用全由你定；洗牌、撤回每局各送 3 次，用完了不会自动补。

📅 每日与解锁

每日挑战：所有人同一牌面、步数固定，目标分随日期递增。每日任务：每天 3 个，完成后去任务面板领金币，连续签到 7 天奖励递增。

主线 20 关，通过才解锁下一关；注销会清空全部进度，不可恢复。

# 奶龙消消乐 · Nailong Match

纯前端三消小游戏，无框架、无构建、无依赖。

## 运行

- 直接双击 `index.html`：`levels.json` 会被浏览器拦截，自动用 `js/game.js` 里的 `LEVELS_FALLBACK` 兜底，玩法一致。
- 想改关卡生效就起个静态服务：`python -m http.server 8000`，打开 `http://localhost:8000`。

## 玩法

- **主线**：80 关 8 章（草地 → 海洋 → 星空 → 糖果 → 森林 🌿 → 云端 ☁️ → 沙漠 🏜️ → 熔岩 🔥），每章 10 关，章节剧情只有「继续前进」一个键。
- **交换**：点选再点相邻块，或拖到相邻格；退出 / 切后台自动暂停。
- **目标（8 种）**：分数 / 收集方块（开局随机图案，续玩不重挑）/ 清果冻 / 限时 / 极限步数 / 敲冰块 / 运送钥匙（第四章起混糖果 🍬）/ 护送奶龙。
- **障碍**：冰块（2~3 层，相邻消除砸开）、锁链（消一次解链）。货物贴在方块上跟着下落，被消时落到本列下面最近的方块上，**送到最底行才算送达**（送达统一 +150 分）；一格可叠多件货，洗牌只洗方块、货物不动。
- **特殊块**：
  - 4 连 → 线消（清整行 / 整列）；L/T → 炸弹（3×3）；
  - 5 连 → 彩虹 🌈（被消时清全场同图案）；
  - 6 连 → 磁铁 🧲**（吸走同行同列同色 + 3×3）；
  - 7 连 → 颜料 🎨**（把一片刷成同色）；
  - 大 L/T（≥7 格）→ 螺旋桨 🛩️**（斜扫两条对角线）；
  - 霜块 ❄️**（每 6 步自动长一个，消掉后 3 步内机关全部暂停）。
- **组合技**：两个特殊块交换触发——线消×2 / 线消+炸弹 / 炸弹×2 / 彩虹+线消 / 彩虹+炸弹 / 彩虹×2，以及超级融合：**彩虹+磁铁 = 磁力虹吸、炸弹+磁铁 = 磁力爆破、磁铁+磁铁 = 双磁十字**，霜块 / 颜料 / 螺旋桨也有各自融合，任意两个特殊块相碰都有效果。
- **机关（第五章起）**：目标栏下方的黄色小胶囊实时报数——
  - 常春藤 🌿**：每 3 步蔓延一格，消掉藤蔓上的方块割掉它，长满 26 格直接失败；
  - 保险箱 📦**：旁边消 2 下敲开，掉出糖果；
  - 流沙 🟫**：底行有沙的列送不了货，每 3 步埋掉沙上的货，消掉沙上方块挖走；
  - 移动轨道 🚄**：每 4 步整行滑一格；
  - 步数炸弹 ⚠️**：倒计时归零直接失败，消掉该格拆除（+120 分）；
  - 迷雾 🌫️**：盖住的方块看不见，消掉旁边显形；
  - 传送门 🌀**：成对出现，货物落上一扇门直接跳到另一扇。
- **连击**：1600ms 窗口内接着消算连击（×1.5 / ×2 / ×3），4 连击触发 6 秒狂热双倍；连击弹窗只停留 620ms。
- **星级**：1 星过关，2/3 星看分数线或剩余步数比例；星星只升不降，重打不掉星。
- **一格一物**：钥匙 / 奶龙 / 冰 / 锁链 / 特殊块互不重叠，特殊块生成时自动换到本轮要消掉的空格。
- **目标口径**：目标数 = 已完成 + 场上还剩（`syncGoalFromBoard` 开局 / 读档 / 每次结算后校准），不会出现打不过去的死局。
- **音效**：碎冰、炸弹、彩虹等都有专属合成音（`js/audio.js`），BGM 与鼓点提前排程不卡顿。
- **按键**：结算面板「继续游戏」键绿色、宽度包住文字；关卡记录右下角「结算」键为小号黄色胶囊。
- **其他**：每局 3 次提示 / 3 次洗牌 / 3 次撤回、失败可花 300 金币续命、步数用完绝不自动消耗背包道具、主页进度跟随最后进入的关卡。
- **章节奖励**：一章全拿星 → 邮箱自动发「恭喜通过第X章」+ 200 金币（id 固定不重复发）。
- **商店 / 背包**：+3 步（300）、+7s（300，限时关专用）、洗牌 +1（150）、撤回 +1（150）、开局线消 / 炸弹（200）、彩虹（500）。
- **每日任务**：池子 10 个每天抽 5 个、尽量整批换新；奖励只有 20 / 40 / 60 三档且每天每档至少一个；货物送达也计分。
- **签到**：每天固定 50 金币，连续满 7 / 14 / 21… 天额外送 200 金币进邮箱（补签 300 金币/天）。
- **成绩单**：关卡记录右下角「结算」随时打开——称号（学徒 → 宗师）+ 四格数据（数字 900ms 滚动），标题「🎉 恭喜」为彩虹色，卡片垂直居中、装饰横线恒满。
- **成就**：25 枚五阶（灰铜银金彩），升阶奖 50 / 100 / 150 / 200 金币；详情页整页随阶变色、彩杯用彩虹图填色，滑动可切成就，没领的有红点。
- **棋盘配色**：8 款按总星星解锁，第 8 款「彩色」光晕为柔彩虹渐变。

## 账号与邮箱

- **本机多账号**（`js/account.js`）：名字唯一（1~8 字符、区分大小写）、密码 4~24 位；同名无密码老账号注册时直接接管。
- **云端账号**（`js/cloud.js`）：Cloudflare Pages Functions + D1，密码 PBKDF2 加盐；进度每 30 秒自动上云，换设备登录即拉回；云端不可达静默降级本机。
- **云存档自动化**：记着密码就系统自己存（密码轻混淆留本机），不用玩家点；改名 / 改密码同步服务器，只认本账号令牌。
- **默认昵称闸门**：昵称还是「奶龙玩家」时强制弹改名窗，改完才放行。
- **注销**：本机 + 服务器一起删（不可恢复），设备停机牌防止旧存档被拉回。
- **邮箱 📮**：系统公告与奖励，带附件点「领取」；标题带「：」自动拆主副标题；左滑删除。
- **存档码**：账号安全页生成（`NL2BK1.` 开头整份搬回），登录页可导入。
- **排行榜**：总榜 / 省榜 / 局榜，星星贴在分数左边，固定列对齐不挤偏。
- **音乐**：自带歌曲只在音乐库，导入与删除两库互不同步；恢复默认先弹确认。

## 目录

```
index.html        页面骨架 + 所有面板
css/              style.css 基础布局、themes.css 主题与组件
js/game.js        主控：棋盘、交换、消除、动画、结算、面板
js/levels.json    80 关数据
js/{meta,board,music,audio,builtin-music,storage,tasks,specials,goals,effects,input,rng,account,mail}.js
assets/           六种方块贴图（webp，512×512，单张 25-80KB）+ music/
test-smoke.js     无头冒烟测试（node test-smoke.js）
test-longpress.js 播放列表长按拖动测试（node test-longpress.js）
```

脚本加载顺序（`index.html` 底部）不能乱：`rng → storage → audio → effects → specials → goals → tasks → mail → input → builtin-music → music → meta → account → board → game`。

## 存档

全部在 `localStorage`，前缀 `nl2:`；每个账号一份快照 `nl2:acc:<id>`，切换时与当前数据互相倒腾。设备级 key：`nl2:accounts` / `nl2:cur` / `nl2:comp` / `nl2:visits` / `nl2:net` / `nl2:lb-del` / `nl2:statsVer` / `nl2:purged` / `nl2:acc:*`，注销和切换都不动它们。

## 已知限制

- 排行榜走 ntfy.sh 公共主题（`nailong-lb-9k2v7h4q`），SSE 实时收更新 + 本地缓存；中转只留约 12 小时，客户端定期合成整榜快照。`file://` 和 localhost 不发布成绩（防测试污染）。
- `file://` 下读不到 `levels.json`，走内置数据兜底。
- `_legacy/` 是重构前的单文件旧版，仅作参考，已加入 `.gitignore`。

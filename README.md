# 奶龙消消乐 · Nailong Match

纯前端的三消小游戏，无框架、无构建、无依赖。双击 `index.html` 就能玩。

## 🚀 运行

**方式一：直接打开**

双击 `index.html`。

此时浏览器会拦截 `fetch('js/levels.json')`，游戏会自动回退到内置关卡数据（`js/game.js` 里的 `LEVELS_FALLBACK`），玩法完全一致。改 `levels.json` 想生效就得用方式二。

**方式二：起个静态服务（推荐）**

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```

## 🎮 玩法

- **交换**：点一块选中，再点相邻块；或按住拖到相邻格松手；长按可多选
- **目标**：每关目标不同 —— 分数 / 收集指定颜色 / 清除果冻格 / 限时 / 极限步数 / 敲碎冰块 / 运送钥匙 🔑 / 护送奶龙（棋盘上直接用奶龙抠图）
- **障碍**：冰块冻住的方块不能动（厚冰 2 层，靠相邻消除砸开）；锁链第一次被消只解链；货物（钥匙/奶龙）贴在方块上跟着下落，落到最底行才算送达；货物所在方块被消掉时，货物落到被消掉那一格的下面一格（不会从顶端重来）
- **特殊块**：横 4 连 → 横线块，竖 4 连 → 竖线块，L/T 型 → 炸弹，5 连 → 彩虹（消全盘同图案方块，彩虹自己也一起消掉；掉落补位凑出的普通三连照常连消）
- **组合技**：两个特殊块相邻交换触发合体效果 —— 同向线消×2 → 三行/三列，垂直线消×2 → 十字爆破，线消+炸弹 → 十字炸弹，炸弹×2 → 5×5，彩虹+线消/炸弹 → 同图案变身，彩虹×2 → 全屏清场
- **连击**：连续消除叠倍率 x1.5 / x2 / x3；4 连击触发狂热 6 秒，期间分数再翻倍
- **提示**：每局 3 次，点 💡 高亮一组可走的交换
- **续命**：主线关卡失败时可花 200 金币再来一次（+3 步 / +15 秒），每局 1 次，每日挑战和更多玩法不提供
- **撤回**：回到上一步走之前的棋盘，连锁消除与目标进度一起退回
- **自动暂停**：退出页面 / 切后台 / 锁屏都会自动暂停，不白掉步数
- **星级**：每关 1~3 星，主页显示总星数
- **主线**：40 关 4 个章节（奶龙的草地午后 / 奶龙海底捞钥匙 / 奶龙闯星空 / 奶龙的糖果城堡），每章开头有剧情可跳过，章节地图里看进度
- **更多玩法**：无尽模式（40 步）、60 秒冲刺、节奏关卡（棋盘下方节拍条 + 滴答声，踩节拍 ×1.5），最佳分单独记录
- **每日挑战**：每天同一套棋盘（日期做种子），3 星后当天封盘，显示「已完成今日挑战」和当日战绩
- **成长系统**：成就 19 枚（每枚 5 阶：灰 → 铜 → 银 → 金 → 彩，按进度依次升阶；「奶龙守护者」的图标直接用奶龙抠图）、棋盘配色 8 款（黄/红/橙/绿/青/蓝/紫/黑，按星星解锁，只改棋盘光晕 + 目标栏底色）、福利中心（签到 + 每日转盘）、排行榜（总榜 / 省榜 / 局榜，先选榜单再进列表）
- **账号**：本机多账号（`js/account.js`）。第一次进入链接先选「登录 / 注册」；注册输名字 + 密码（4~24 位，不能有空格），登录名字或密码输错会输入框变红并提示「名字或密码不正确，请确认后再次输入」。名字含敏感词（如「黄君丽」）同样输入框变红，提示「改名字含敏感词，请重新输入」；已存在的账号名字含敏感词、或账号缺名字 / 缺密码时，会弹强制窗口补齐才能玩。名字最多 8 字，特殊符号只允许 `-` `.` `_`，且不能重名
- **切换账号**：设置 → 🔐 账号安全 → 🔄 切换账号（点账号条目直接进）；只是想换个号玩用「切换账号」或「登录其他账号」（退出登录，数据留在本机快照）
- **注销账号**：设置 → 🔐 账号安全 → 🔒 注销账号（切换账号下面），两步确认后**彻底删除**这个号——本机存档、账号表记录、邮箱、进度、金币、成就全部清掉，并向共享榜广播删除成绩，不可恢复
- **邮箱**：主页左上角 🏠 主页键**下面的 📮 邮箱键**收系统公告和奖励（`js/mail.js`），有新邮件亮红色角标；带附件的邮件可领金币，每封只能领一次，已读 / 领取记录跟随账号
- **发奖励**：金币一律**发到邮箱**（邮件附件，玩家自己点「领取」才到账），不直接进钱包。指定玩家的奖励在 `js/account.js` 的 `GRANTS` 里加一条（名字大小写不敏感、每账号只发一次），`Mail.SYSTEM_MAILS` 支持用 `to: '名字'` 定向
- **后台（完全隐藏）**：入口不告诉玩家——主页同时按住奶龙图案 + 🏠 主页键 3 秒进入；一级「📊 点击数量」（全网 / 本机）/「👥 全服用户」（用户数量 = 有名字 + 有密码的账号，不在榜上也算；省份数量 = 这些账号所在的省，本机账号取定位省、榜上玩家取发成绩时的省）；省份统计在「点击数量」页里**同时按住 🔧 后台标题 + 🌐 全网 3 秒**进入，没有任何可见按钮
- **修改密码**：设置 → 🔐 账号安全 → 🔑 修改密码（原密码 + 新密码 + 确认）
- **奖牌**：局榜前三名显示 🥇🥈🥉（榜上只有自己一个人也算名次）；主页奖牌贴在「本关最高分」的**分数左边**，关卡记录里贴在**星星左边**。0 分不算上榜，榜上显示「未上榜」
- **福利中心**：签到 7 天一轮 + 每日转盘；最下面显示「连续签到 N 天」，漏签的日子可花 300 金币补签 1 天（只补连续天数，不发当日奖励）
- **续玩剩余步数**：主线限步关结算时若还有剩余步数，「进入下一关」上面会出现「还有剩余步数 N 步，是否继续游戏」，点了回到棋盘接着刷分（步数用完再结算一次，金币照发）

## 🏠 主界面

主页左上角：🏠 主页键在上（里面是「✏️ 改名」）、📖 规则键在下（点开先选「🧩 功能介绍」或「🎮 玩法规则」，功能介绍讲系统功能、玩法规则讲单局玩法，分开解释）；右上角是 ⚙️ 设置 / 🎵 音乐 / 🎒 背包。

主页按钮（两行宫格）：

`🗺️ 章节地图` → `🎮 更多玩法` → `🏆 关卡记录` → `📅 每日挑战` → `🎯 每日任务` → `🎁 福利中心` → `🛒 购物商店` → `🎨 棋盘配色` → `🏅 成就` → `📊 排行榜`

游戏界面工具栏两排：第一排 `NEXT 预览 · 🎵 音乐 · 🎒 背包 · 📖 规则 · ⚙️ 设置`，第二排 `💡 提示 · 🔄 洗牌 · ↩️ 撤回`（从游戏里打开规则/设置会自动暂停，关掉自动接上）。

**关卡记录里点任意一关，会回到主页并把主页切换到那一关**，再点「开始游戏」就从那关打。已通关但没拿满星的关卡会显示 `★★☆`。

## 🎵 音乐

设置（右上角 ⚙️）→ 🎵 音乐设置 →

- **播放列表**：左滑条目出现「重命名 / 删除」；长按进入多选，可批量删除；支持顺序 / 随机 / 循环三种模式。长按拖动排序在**安卓触屏**上同样可用（触摸手势直接接管，拖动时列表不会跟着滚）
- **导入音频**：粘贴 MP3 直链保存即播，同时进历史导入和播放列表
- **音乐库**：与历史导入共用数据，左滑可「重命名 / 添加到播放列表 / 删除」

音频必须是能直连的 `.mp3` 地址，跨域或需要登录的链接会加载失败。

## 💾 存档

全部存在 `localStorage`，key 前缀 `nl2:`：

| key | 内容 |
|---|---|
| `nl2:meta` | 版本号，用于迁移 |
| `nl2:progress` | 每关最高分 + 星级 |
| `nl2:wallet` | 金币 + 道具数量 |
| `nl2:tasks` | 每日任务进度、签到天数 |
| `nl2:settings` | 音量、音乐开关、主页选中关卡 |
| `nl2:save` | 当前局的棋盘与进度 |
| `nl2:musicHistory` / `nl2:playlist` / `nl2:playMode` | 音乐数据 |
| `nl2:mstats` / `nl2:mach` / `nl2:macht` / `nl2:mskin` / `nl2:mskins` | 成就统计、已解锁成就、成就阶数、当前皮肤、已解锁皮肤 |
| `nl2:mwheel` / `nl2:mboard` / `nl2:mbest` / `nl2:mstory` / `nl2:mnick` | 转盘、旧周榜（仅迁移好友）、模式最佳分、章节剧情、昵称 |
| `nl2:lbshare2` | 共享排行榜缓存（全网名单 + 每关最高分 lv + 省份代码 pv，来自公共中转） |
| `nl2:lb-del` | 已注销玩家的墓碑表（防止旧消息 / 老快照把注销的人复活） |
| `nl2:accounts` / `nl2:cur` / `nl2:comp` | 账号表（名字 + 口令哈希）/ 当前登录的账号 id / 已领取的补偿 |
| `nl2:acc:<id>` | 每个账号一份存档快照，切换账号时与当前 `nl2:*` 互相倒腾 |
| `nl2:mail` | 邮箱的已读 / 领取记录（跟着当前账号走） |

这些是**设备级** key：`nl2:accounts` / `nl2:cur` / `nl2:comp` / `nl2:visits` / `nl2:net` / `nl2:lb-del` / `nl2:statsVer` / `nl2:acc:*`，切换账号、注销都不动它们；其余 `nl2:*` 都属于当前账号，切换时整体存进快照再铺回目标账号的数据。

## ⚠️ 已知限制

- 方块贴图用 `assets/*.webp`（512×512，单张 25~80KB，合计约 260KB），首屏 `<link rel="preload">` 预加载；`.jpg` 原图（每张 1~2MB）只作留档，页面不再请求。
- 排行榜走一个无服务器的小系统：所有人的成绩发到一个固定的 ntfy.sh 公共主题（`nailong-lb-9k2v7h4q`；旧主题 `nailong-lb-7c41d9e2` 曾被验证期的测试成绩污染，已弃用），开着排行榜时用 SSE 实时收别人的更新，关着时下次进来拉一次历史；本地留一份缓存，断网也能看。中转只保留约 12 小时消息，所以客户端会定期合成整榜快照（总分一条 + 局分按 10 关一批轮发）把老成绩传下去。`file://` / localhost 环境一律不发布成绩（防测试污染）。早期成绩码导入的好友依然保留在榜上（左滑删除），但界面已不再提供新增入口。
- `file://` 下 `levels.json` 读不到，走内置数据兜底。

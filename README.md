## ✨ 游戏特色

- 🎮 **纯前端零依赖**：无需构建，无需后端，丝滑加载。
- 🖼️ **自定义图片方块**：支持随意替换 `assets` 中的奶龙图片。
- 🎯 **纯得分挑战**：每关只有得分目标，步数耗尽且分数达标才算过关！
- 💣 **炸弹机制**：4 连消生成 💣 炸弹方块，炸弹被消除时引爆，炸毁周围一圈，并支持连锁引爆。
- 🌈 **彩色方块**：5 连消生成彩虹彩色方块，点击可引爆全场所有炸弹；步数用完仍未点击，系统会自动触发并计分。
- 🚀 **爽快特效反馈**：消除有粒子爆炸、得分飘字、连击音调递增、手机震动；炸弹引爆有冲击波环 + 大量火花，音效低频柔和不刺耳。
- 🛠️ **实用小道具**：每局自带 3 次“洗牌”和 3 次“撤回”机会，拯救死局。
- 🔒 **关卡线性解锁**：必须达标通关前一关，才能解锁下一关，最高 20 关。
- 🏆 **历史成绩记录**：自动保存每关最高分；未通关的分数也会记录并标红显示，方便查看差距。
- 💾 **断点续玩**：自动保存当前棋盘状态，退到主页或关闭网页，下次打开可直接“继续游戏”。
- 🗑️ **注销功能**：主页右下角可清除所有本地数据，两段确认防误触。
- 📱 **全端适配**：完美支持手机触摸与电脑鼠标操作，自适应屏幕尺寸。

## 🎮 玩法说明

1. 点击一个方块选中，再点击**相邻**方块交换位置。
2. 横向或纵向连成 **3 个及以上**同色方块即消除。
3. 消除后上方方块下落，可能触发**连锁消除**（连击得分翻倍）。
4. 凑齐 **4 个**同色方块，生成一个 **💣 炸弹方块**。
5. 炸弹**参与三连被消除**时引爆，炸毁周围一圈；炸到其他炸弹会连锁引爆。
6. 凑齐 **5 个**同色方块，生成一个 **🌈 彩色方块**。
7. 点击彩色方块，**直接引爆棋盘上所有炸弹**；若步数用完仍未点击，系统自动触发并计分。
8. 步数归零时，分数达到关卡目标即过关进入下一关；未达标则失败，且**不会解锁下一关**。
9. 通关后自动解锁下一关，可在“历史关卡记录”中重玩已解锁的关卡。
10. 主页右下角“注销”可清除所有存档，回到初始状态。

## 🧩 关卡与难度

- 每关固定 **25 步**。
- 关卡目标分：`2200 + (关卡数 - 1) × 200`（第 1 关 2200 分，第 20 关 6000 分）。
- 棋盘尺寸固定为 **8 × 8**，共 **6 种**方块类型。
- 初始棋盘保证无三连，且每步操作后自动检测死局，若无可行步则自动重洗。
- **未通关也会记录得分**（历史记录中红色显示），但**不解锁下一关**；只有达标通关才解锁。

## 🔧 自定义方块图片

将你喜欢的图片命名为 0.jpg ~ 5.jpg，放入 assets/ 目录即可（代码默认加载 .jpg）。<br>
图片建议为正方形（如 128×128）。若图片加载失败，游戏会自动回退为彩色圆角方块，不影响游玩。<br>
> 如需使用 PNG，可把 `js/game.js` 中的图片路径 `.jpg` 改成 `.png`。

## 🛠️ 技术要点

- Canvas 渲染：所有方块、选中框、粒子、飘字均由 Canvas 绘制，配合 requestAnimationFrame 实现交换/消除/下落动画；方块带圆角、投影、高光渐变，呈立体质感。
- Web Audio 合成音效：不依赖任何音频文件，通过 OscillatorNode 实时合成选中、交换、消除、炸弹、过关、失败等音效，连击时音调递增。
- 炸弹连锁：炸弹只在自身被消除时引爆，炸到其他炸弹会加入队列继续引爆，并生成冲击波粒子。
- 本地存档：使用 localStorage 保存关卡最高分（nailong_level_scores）与当前对局状态（nailong_save）。
- 适配策略：根据窗口宽度动态计算格子尺寸，resize 时自动重绘；棋盘外层 .board-wrap 承载留白与阴影，避免 canvas 尺寸抖动。
- 动态加载：index.html 用时间戳加载 CSS/JS，避免浏览器缓存旧版本。

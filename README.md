# 奶龙消消乐 · Nailong Match

纯前端的三消小游戏，无框架、无构建、无依赖。双击 `index.html` 就能玩。

## 🚀 运行

**方式一：直接打开**

双击 `index.html`。

此时浏览器会拦截 `fetch('js/levels.json')`，游戏会自动回退到内置关卡数据（`js/game.js` 里的 `LEVELS_FALLBACK`），玩法完全一致。改 `levels.json` 想生效就得用方式二。

**方式二：起个静态服务（推荐）**

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```

## 🎮 玩法

- **交换**：点一块选中，再点相邻块；或按住拖到相邻格松手
- **目标**：每关目标不同 —— 分数 / 收集指定颜色 / 清除果冻格 / 限时 / 极限步数
- **特殊块**：横 4 连 → 横线块，竖 4 连 → 竖线块，L/T 型 → 炸弹，5 连 → 彩虹（彩虹只消全盘同图案的方块）
- **组合技**：两个特殊块相邻交换会触发合体效果（同向线消×2 → 三行/三列、垂直线消×2 → 十字、线消+炸弹 → 十字炸弹、炸弹×2 → 5×5、彩虹+线消/炸弹 → 同图案变身、彩虹×2 → 全屏清场）
- **连击**：连续消除叠倍率 x1.5 / x2 / x3，HUD 顶部有连击条
- **撤回**：回到上一步走之前的棋盘，目标进度也一起退回
- **自动暂停**：游戏中退出页面 / 切后台 / 锁屏都会自动暂停，不白掉步数
- **星级**：每关 1~3 星，主页显示总星数
- **主线**：20 关，每 5 关一个 BOSS 关，第 20 关通关后有结算面板（关卡记录里可随时「重现结算画面」）
- **每日挑战**：每天同一套棋盘（日期做种子），拿到 3 星后当天封盘，显示「已完成今日挑战」和当日战绩

│   ├── levels.json       20 关关卡数据（目标类型 / 步数 / 星级阈值 / 主题）
│   ├── music.js          音乐播放列表 / 历史导入 / 重命名 / 播放模式

│   ├── tasks.js          每日任务、每日挑战、商店
│   ├── specials.js       特殊块判定、连锁展开、组合技矩阵
│   ├── goals.js          5 种目标类型判定 + 星级计算
│   ├── effects.js        粒子 / 文字 / 冲击波对象池
│   ├── input.js          Pointer Events 拖拽 + 点击
│   └── rng.js            种子随机（每日挑战用）
├── .gitattributes
├── .gitignore
├── README.md
├── index.html            页面骨架 + 所有面板

脚本加载顺序（`index.html` 底部）不能乱：`rng → storage → audio → effects → specials → goals → tasks → input → music → game`。

## 🏠 主界面

主页按钮从上到下：

`开始游戏` → `重新开始本关` → `🏆 关卡记录` → `📅 每日挑战` → `🎯 每日任务` → `🛒 商店`

**关卡记录里点任意一关，会回到主页并把主页切换到那一关**，再点「开始游戏」就从那关打。已通关但没拿满星的关卡会显示 `★★☆`。全部通关后，关卡记录里会出现「重现结算画面」按钮，用最新数据回放通关结算。

**商店购买道具有二次确认**，确认后才扣金币，防止误买。

## 🎵 音乐

设置（右上角 ⚙️）→

- **播放列表**：左滑条目出现「重命名 / 删除」；长按进入多选，可批量删除；支持顺序 / 随机 / 循环三种模式
- **导入音频**：粘贴 MP3 直链保存即播，同时进历史导入和播放列表
- **音乐库**：与历史导入共用数据，左滑可「重命名 / 添加到播放列表 / 删除」

音频必须是能直连的 `.mp3` 地址，跨域或需要登录的链接会加载失败。

音量方面：所有歌（含内置音乐）响度自动对齐；「调节音量」拖滑块实时试听当前播放的音乐；音量会记忆，下次打开与上次退出一致；音乐键只控制背景音乐，游戏音效不受影响。

## 💾 存档

全部存在 `localStorage`，key 前缀 `nl2:`：

| key | 内容 |
|---|---|
| `nl2:meta` | 版本号，用于迁移 |
| `nl2:progress` | 每关最高分 + 星级 |
| `nl2:wallet` | 金币 + 道具数量 |
| `nl2:tasks` | 每日任务进度、签到天数 |
| `nl2:settings` | 音量、音乐开关、主页选中关卡 |
| `nl2:save` | 当前局的棋盘与进度 |
| `nl2:musicHistory` / `nl2:playlist` / `nl2:playMode` | 音乐数据 |

主页右下角「注销」会清空以上全部内容。

## ⚠️ 已知限制

- 素材 `assets/*.jpg` 是原图（每张 1~2MB，合计约 11MB）。想减小体积可以压到 200KB 以内，画质在棋盘尺寸下看不出差别。
- 没有后端，也没有排行榜；每日挑战是「同一天所有人同一套棋盘（日期做种子）」，成绩只存在本地。
- `file://` 下 `levels.json` 读不到，走内置数据兜底。

# 奶龙消消乐 · Nailong Match

纯前端三消小游戏，无框架、无构建、无依赖。

## 运行

- 直接双击 `index.html`：`levels.json` 会被浏览器拦截，自动用 `js/game.js` 里的 `LEVELS_FALLBACK` 兜底，玩法一致。
- 想改关卡生效就起个静态服务：`python -m http.server 8000`，打开 `http://localhost:8000`。

## 玩法

- **交换**：点选再点相邻块，或拖到相邻格；长按可多选。
- **目标**：分数 / 收集方块（每次开局随机两种图案，「继续游戏」恢复本局不重挑，消掉的目标方块实时计数）/ 果冻格 / 限时 / 极限步数 / 敲冰块（2 层起，厚冰 3 层）/ 运钥匙 🔑 / 护送奶龙。
- **障碍**：冰块冻住的块不能动，靠相邻消除砸开；锁链消一次解链；货物贴在块上跟着下落，落到最底行才算送达。钥匙 / 奶龙徽标都带**黑色描边**（奶龙是抠图剪影沿 8 个方向铺边；钥匙是纯 Canvas 路径画的，先用加粗黑线描一遍再填金色渐变，省得靠 emoji——彩色 emoji 不吃 `strokeText`，描边等于没画），按屏幕 DPR 栅格化，任何底图上都看得清。
- **一格一物**：钥匙 / 奶龙 / 冰 / 锁链 / 特殊块都是「占了这格」的东西。生成特殊块时如果预定格子（`Specials.planCreation` 给的坐标）已经有东西，就从**本轮要消掉的格子**里另挑一个空位（`canPlaceNew()` + `pickSpotIn()`），没有空位就不生成；背包放炸弹 / 线消 / 彩虹、开局炸弹同样只挑空格；被消方块踢下来的货物也只会落到非特殊块上，绝不两样叠在一起。
- **目标口径（冰块 / 钥匙 / 奶龙）**：目标数永远 = 「已完成 + 场上还剩」，`syncGoalFromBoard()` 在开局、读档、每次结算后各校准一次，所以数字和棋盘上数得出来的一致。冰块按**块**算（厚冰要砸透才算清掉一块，不再按层数把目标虚高成两倍）。货物被顶下时先在原列往下找位、再往上、然后全盘找空位，实在没有才贴回原位 —— 绝不凭空消失（丢一只奶龙 = 那关永久打不过）。
- **特殊块**：横/竖 4 连出线消，L/T 出炸弹，5 连出彩虹；两个特殊块相邻交换触发组合技。引爆有专属特效（`js/effects.js`）：炸弹火球冲击波 + 全屏闪光 + 震屏，线消蓝光束横 / 竖扫过，彩虹五色波纹 + 白闪。棋盘方块底色用各自图案色加深 25%（`tileBaseColor`），不再是黑色；彩虹特殊块是图案方块叠 🌈 emoji（drawSpecialOverlay）；`assets/rainbow.jpg` 彩虹图用在棋盘配色列表「彩色」行的图标上。
- **其他**：连击倍率、4 连击狂热（6 秒双倍；表现是**棋盘正下方**一枚静态倒计时小标「🔥 双倍 Ns」（`.frenzy-slot` 固定占位，出现 / 消失都不挤动棋盘），逐秒递减，棋盘不做呼吸闪动 / 亮度变化，避免看着晃眼）、每局 3 次提示（照着高亮的交换走那一步、洗牌或撤回后 `clearHint()` 立刻收掉高亮框）、失败可花金币续命、可撤回、切后台自动暂停、1~3 星。中央连击弹窗只停留 620ms（`COMBO_DECAY`），淡出 0.16s，不长时间挡棋盘。全局提示条（toast）停留 3 秒。后台「全服玩家 / 省份」搜索框**区分大小写**（输 `yone` 不再匹配 `YONE`）。步数 / 时间用完**绝不自动消耗背包道具**（`autoUseLeftoverItems` 已整体删除），只保留花金币续命的机会。过关时还有剩余步数 / 剩余时间，结算面板会多一个「还有剩余步数／秒数是否继续游戏」的按钮（限时关点完 `startTimer()` 继续跑表，时间到 = 第二次结算 `levelWin(true)`，不是失败）；失败标题限时关写「时间到了」，步数关写「步数耗尽」。主页「📍 当前进度」跟随最后进入的关卡（`startLevel` 写入 `settings.menuLevel`），从哪关出去主页就停在哪关。关卡记录和章节地图打开时都会把当前关卡平滑滑到列表中间；主页不可上下滚动；所有滑动区域不显示滚动条灰线。
- **内容**：主线 40 关 4 章；更多玩法（无尽 / 60 秒 / 节奏）；每日挑战（日期做种子）；成就 27 枚五阶、棋盘配色 8 款（第 8 款「彩色」：光晕为柔彩虹渐变，列表里所有配色图标都是 20px 铺满小方块，彩色用 assets/rainbow.jpg 彩虹图，其余用对应纯色）、签到入口（日期条签到 + 转盘）、排行榜（总榜 / 省榜 / 局榜）。章节剧情过场只有「继续前进」一个键（原来的「跳过剧情」已删）。
- **总分口径**：只累加**已通关（星数 > 0）**关卡的最高分；没过关那一局的分数不进总分，也不参与「最高单关」判定，通关拿到星以后才加。排行榜（`myBestEntry`）、结算画面（`showCompletePanel`）、后台统计（`totalBestScore`）统一走这个口径。

## 账号与邮箱

- 本机多账号（`js/account.js`）：进入先登录 / 注册，名字唯一、4~24 位密码，名字含敏感词会被拦。**名字区分大小写**：`Yone` 和 `yone` 是两个不同的号（`nameKey` 只 trim 不转小写，服务端 `nickKey` 同理，D1 `nick_key` 已迁成原样）；登录时精确匹配优先，输错大小写且**只有一个**大小写不敏感候选时自动找回（`findByNameLoose` / 服务端 `lower(nick_key)` 兜底），同名不同大小写都在时不做猜测。**登录 / 注册 / 补资料页面不播背景音乐**，进主界面后才有。
- 云端账号（`js/cloud.js` + `js/cloud-config.js`）：后端是 Cloudflare Pages Functions + D1 数据库，接口 `${endpoint}/api/rpc/nl_*`（`register` / `login` / `load` / `save` / `setpass` / `rename` / `delete`），密码 PBKDF2-SHA256 加盐存库、明文不落库。登录成功后本地账号静默建档上云，进度每 30 秒推一次、`pagehide` 再强推一次；换设备 / 清缓存后用同一个名字密码登录即拉回存档。云端不可达时静默降级为纯本机，不影响游玩。
- 账号上云（`Account.pushAccountToCloud`）：本机账号在服务器上没有时，主页提示「☁️ 把账号存到服务器」（账号安全页也有常驻入口 `#btn-goto-cloud`），玩家输一次自己的密码——本机比对哈希通过后，用**同一名字 + 同一密码**去服务器建档并合并存档，不改密码、不留明文。窗口只有黑色「存到服务器」一个按钮，**没有跳过项**：`cloudForced` 锁住，遮罩不关、`hideAllOverlays` 顶回来，只有存成功才关。
- 注册即上云：`register()` 末尾调 `bgRegister(acc, 明文密码)` 自动建档；补密码的老账号在 `saveFix()` 后也会走一次上云。改名 / 改密码分别用 `nl_rename` / `nl_setpass` 同步，且**只认本账号自己的 `acc.ctoken`**（避免误用设备上别人的令牌改到别人的号）。
- 存服务器窗口的逃生口：`pushAccountToCloud` 遇到「服务器上已有同名号且密码对不上」（玩家在另一个链接用别的密码先占了名）时返回 `nameTaken`，云窗口此时出现「✏️ 改个名字再存」（`#btn-cloud-rename`，平时隐藏）——点击释放 `cloudForced`、进入改名窗，改完自动回到存档窗重存；没有这个口子，「关不掉的存档窗」会把玩家永久锁在页面里。另外 `pushCloud` 遇到令牌过期会自动解除本机绑定（`ctoken/cloud` 清空），让「存到服务器」能重新提示。账号安全页的常驻入口**不看绑定标记下结论**：已绑定的号点击时先 `pushCloud(true)` 真实推送验证——推成功提示「进度已同步」；号被后台删过则令牌过期自动解绑、照常弹存档窗重新建档，避免「服务器号没了、本机还显示已存」的假绑定。
- 默认昵称闸门：昵称还是「奶龙玩家」时，进主页 / 点开始游戏都会弹出**关不掉的改名窗口**（`#nick-menu`，无返回键、点遮罩不关、`hideAllOverlays` 也会把它顶回来），改名成功才自动关闭并继续；输入框强制态下留空，防止点一下就过。改名同步写回服务器（`nl_rename`），榜单立刻更新。
- 设置 → 账号安全：切换账号 / 修改密码 / 注销账号（彻底删除本机存档、邮箱、进度、金币，不可恢复）。
- 注销要连服务器一起删（`Account.purge()` + `Cloud.remove()` → `nl_delete`）：只清本机会让玩家注销后用同样的名字再登录时，云端把旧存档整套拉回来（进度看着一点没变）。客户端等删除请求返回后再刷新页面（最多 2.5 秒）；另外记一张设备级停机牌 `nl2:purged`，万一这次网络没删干净，同名/同身份的云端登录也会被拒（`cloudLogin` 直接回「已注销」并补发一次删除）。重新注册走 `bgRegister` 时以本机这份新存档为准（推送而非拉取），服务器上同名旧存档不会盖回来。
- 共享榜身份码（`js/board.js`）：榜按 `uid` 认人。上云时本机码 `uXXXX` 会迁成服务器码 `pXXXXXX`，旧码那条成绩还留在公共频道和别的设备缓存里，新码再发一次就会**同名出现两条**。两处处理：① `migrateAccId` 迁码时 `Board.remove(旧码)` 广播注销墓碑，别人的榜单立刻撤掉；② `dedupeSameName()` 在进榜 / 收消息 / 发成绩后各收一次——只在「同名 + 一条本机码 + 一条服务器码」时合并成服务器码那条，分数 / 局分取两边最高，两条都是本机码则不动（避免误伤重名玩家）。
- 名字占用只认服务器码：改名 / 注册 / 补资料查重时（`game.js takenNickNames()` + `account.js checkName()`），榜上**只有 `p` 开头服务器身份码**的名字算被占用；本机码 `u…` 的旧榜条目不拦——玩家清缓存 / 换设备后身份码会变，旧条目不该把人家的原名永久锁死（否则丢了账号就永远要不回自己的名字）。
- 无密码老账号的找回（`Account.register` 接管逻辑）：本机账号表里存在**同名且没设过密码**的号时，注册同名直接接管这份账号——保留 id 和存档快照、把新密码设上、顺手 `bgRegister` 上云；不接管的话登录没密码可输、注册又被本机同名号拦住，两头堵死。登录页对 `needPass` 结果给出「去注册用同名设新密码找回」的引导文案。
- 存档码（`Account.exportBackup` / `importBackup`）：两处入口分工——账号安全页「💾 存档码」只有生成框 + 生成 / 复制（生成后压成一段 `NL2BK1.` 开头的文本，含全部账号 + 各号进度）；登录页「💾 导入存档码」只有粘贴框 + 导入 / 返回。换网址 / 换设备 / 微信清缓存后粘回去即可整份搬回（合并式，同 id 覆盖）。
- 主页 🏠 下面的 📮 是邮箱（`js/mail.js`）：系统公告和奖励都发到这里，带附件的邮件点「领取」才到账；左滑出小删除键（轻点不会误触露出），点邮件直接打开详情，一键删除先弹确认窗口。邮件标题带「：」时，详情页自动拆成主标题 + 副标题（副标题单独一行、字号更小），详情页主标题不带 emoji，列表仍显示完整标题。
- 音乐（`js/music.js`）：**系统自带歌曲只放在音乐库**（历史导入里没有）；历史导入和音乐库各存一份（`nl2:musicHistory` / `nl2:musicLibrary`），**删除互不同步**；导入的音频两边都进。恢复默认音乐先弹确认窗口。合成 BGM 与连击鼓点改成**提前排程**（`audio.js` 的 `_bgmNoteAt` / `_drumAt`，每 150ms 把未来 0.9 秒的音排进 WebAudio 时间轴），点按钮 / 棋盘动画卡一下主线程也不会把音乐拖成一卡一卡；手势解锁只在上下文没跑起来（或自定义音乐被暂停）时才 `resume`，不再每次点击都重设一遍音量。
- 局内顶栏（`#hud`）固定只有 **关卡 / 步数 / 得分** 三项（限时关把「步数：」换成「时间：」）；金币、星星原先的 `hud-mini` 项已删——它有 `max-width:420px` 隐藏规则，导致宽窄手机显示不一致。页面容器 `.game-container` 用 `min-height: calc(100dvh - 12px)`（vh 兜底）撑满整屏高度，内容在多出的空间里垂直居中，白色页面随每台手机屏幕高度自适应；宽屏（≥600px）菜单页仍限高 780px。
- 按钮配色：蓝 / 红 / 绿键都是「注销账号」那种描边效果（各自颜色），其余普通键黑色描边；棋盘选中框是黑色（`game.js` 用 `#333`）。所有确认窗口统一：肯定（红）在左、否定（绿）在右，按钮同大。
- 签到（`js/storage.js` + `js/game.js`）：日期条按真实日期显示、横向滑动，本轮 7 天 + 多显示 3 天；签到了绿色、今天虚线框、漏签红色（点击弹补签窗口，`Store.makeupSign(dateKey)` 指定补哪天，300 金币/天）。连续签到天数在签到键上面（黑色）。第 8 款棋盘配色「彩色」：id 仍是 `black`（兼容老存档），meta.js 里改名彩色 + 彩色光晕（柔彩虹渐变外圈）；全服用户页的「用户详情 / 省份详情」按键已删，点击「用户数量 / 省份数量」即进入。。
- 发奖励：`js/account.js` 的 `GRANTS` 加一条（名字不分大小写、每账号一次），邮件正文在 `Mail.SYSTEM_MAILS`。

## 目录

```
index.html        页面骨架 + 所有面板
css/              style.css 基础布局、themes.css 主题与组件
js/game.js        主控：棋盘、交换、消除、动画、结算、面板
js/levels.json    40 关数据
js/{meta,board,music,audio,builtin-music,storage,tasks,specials,goals,effects,input,rng,account,mail}.js
assets/           六种方块贴图（webp，512×512，单张 25-80KB）+ music/
test-smoke.js     无头冒烟测试（node test-smoke.js）
test-longpress.js 播放列表长按拖动测试（node test-longpress.js）
```

脚本加载顺序（`index.html` 底部）不能乱：`rng → storage → audio → effects → specials → goals → tasks → mail → input → builtin-music → music → meta → account → board → game`。

## 存档

全部在 `localStorage`，前缀 `nl2:`；每个账号一份快照 `nl2:acc:<id>`，切换时与当前数据互相倒腾。设备级 key：`nl2:accounts` / `nl2:cur` / `nl2:comp` / `nl2:visits` / `nl2:net` / `nl2:lb-del` / `nl2:statsVer` / `nl2:purged` / `nl2:acc:*`，注销和切换都不动它们。

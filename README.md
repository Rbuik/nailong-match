# 奶龙消消乐 · Nailong Match<>
一个用原生 HTML5 Canvas + JavaScript 写的进阶版三消小游戏，无任何第三方框架依赖，打开即玩！<br>

## ✨ 游戏特色
- 🎮 **纯前端零依赖**：无需构建，无需后端，丝滑加载。
- 🖼️ **自定义图片方块**：支持随意替换 `assets` 中的奶龙图片。
- 🎯 **纯得分挑战**：每关只有得分目标，步数耗尽且分数达标才算过关！
- 💣 **特殊炸弹机制**：4 连消自动生成 💣 炸弹方块，消除时引发连环爆炸，炸毁周围一圈方块。
- 🚀 **爽快特效反馈**：消除伴有粒子爆炸、得分飘字、连击音调变高和手机震动反馈。
- 🛠️ **实用小道具**：每局自带 3 次“洗牌”和 3 次“撤回”机会，拯救死局。
- 🔒 **关卡线性解锁**：必须打通前一关，才能解锁并游玩下一关，最高 20 关。
- 🏆 **历史成绩记录**：自动保存每一关的历史最高分，并支持在“历史记录”中回看与重玩已解锁的关卡。
- 💾 **断点续玩**：自动保存当前棋盘状态，退到主页或关闭网页，下次打开可直接“继续游戏”。
- 📱 **全端适配**：完美支持手机触摸与电脑鼠标操作，自适应屏幕尺寸。

## 🎮 玩法说明
1. 点击一个方块选中，再点击**相邻**方块交换位置。
2. 横向或纵向连成 **3 个及以上**同色方块即消除。
3. 消除后上方方块下落，可能触发**连锁消除**（连击得分翻倍）。
4. 凑齐 **4 个**同色方块，将生成一个 **💣 炸弹方块**，消除它可以炸毁周围一圈方块。
5. 在规定的步数内尽可能多地得分，**当步数归零时，如果分数达到了关卡目标，即可过关进入下一关**；若步数耗尽未达标，则游戏结束。
6. 关卡通关后自动解锁下一关，可在主页的“历史关卡记录”中直接挑战已解锁的关卡。

## 🧩 关卡与难度
- 每关固定 **25 步**。
- 关卡目标分：`1000 + (关卡数 - 1) × 100`（第 1 关 1000 分，第 20 关 2900 分）。
- 棋盘尺寸固定为 **8 × 8**，共 **6 种**方块类型。
- 初始棋盘保证无三连，且每步操作后自动检测死局，若无可行步则自动重洗。

## 🚀 本地运行
由于使用了 assets 图片资源，建议通过本地服务器打开（直接双击 index.html 时部分浏览器会因跨域策略无法加载图片）：
```text
# 任选其一
python -m http.server 8000
npx serve .
```

## 🔧 自定义方块图片
将你喜欢的图片命名为 0.png ~ 5.png，放入 assets/ 目录即可。图片建议为正方形（如 128×128），带透明背景效果更佳。若图片加载失败，游戏会自动回退为彩色圆角方块，不影响游玩。

## 🛠️ 技术要点
- Canvas 渲染：所有方块、选中框、粒子、飘字均由 Canvas 绘制，配合 requestAnimationFrame 实现交换/消除/下落动画。
- Web Audio 合成音效：不依赖任何音频文件，通过 OscillatorNode 实时合成选中、交换、消除、炸弹、过关、失败等音效，连击时音调递增。
- 本地存档：使用 localStorage 保存关卡最高分（nailong_level_scores）与当前对局状态（nailong_save）。
- 适配策略：根据窗口宽度动态计算格子尺寸，resize 时自动重绘。
